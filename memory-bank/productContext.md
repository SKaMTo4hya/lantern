# Product context

People translating Japanese visual novels want to use their own local model and more engines than MTool covers, without paying for a translation tier.

Lantern keeps the original game read-only. The user works in a copy. Ren'Py output is the engine's normal translation folder, so the game loads it after the player selects that language.

A line that fails tag checks is flagged for a human. Already accepted lines are not sent to the model again.
